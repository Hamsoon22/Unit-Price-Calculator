# 👕 Unit Price Calculator  
**패션 제품 단가 & 손익 계산기**

워크숍, 스몰 브랜드, 수작업 제작자들을 위한  
단가/수익 구조 분석 계산기입니다.

React + Vite + Tailwind + Recharts 기반으로 만들었으며,  
1개당 순수익, 손익분기점, 총 수익, 마진율 등을 계산하고 시각화합니다.

---

## ✨ 주요 기능

- ✅ 원단비 / 제작비(개당) / 라벨비 / 마케팅비 입력
- ✅ 제작 수량 vs 예상 판매 수량 입력 가능
- ✅ 판매가에 부가세 포함 여부 선택
- ✅ 자동 계산:
  - 1개당 원가 및 순수익
  - 손익분기점 판매 개수
  - 총 예상 매출
  - 순이익
  - 마진율 (%)
- ✅ 시각화: 원가/순이익 비율 Pie Chart
